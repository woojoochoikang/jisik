# 🥗 지식 — 지루하지 않은 식단

> 냉장고 재료와 개인의 식단 목표를 바탕으로, **오늘 만들 수 있는 맞춤 레시피**를 추천해주는 웹앱

## 🎬 발표 시연 가이드 (데모 사용자: 황성욱)

처음 접속하면 **25세 황성욱**(고혈압·당뇨(2형), 다이어트 목표)의 **시연용 가상 데이터**가 자동으로 채워져요.
하루 목표는 1,600kcal · 단백질 90g · 탄수화물 180g 이하 · 나트륨 1,500mg 이하예요.

**시연 흐름** — 상단 탭에 ①②③ 번호가 붙어 있고, 각 화면 아래 `다음 단계` 버튼으로 이어져요.

1. **📋 오늘의 브리핑** — 접속하면 오늘 섭취량·혈당·혈압·임박 재료·추천 1위와 함께 **부족한 재료 알림**을 보여주고, 그 재료를 **🛒 장바구니에 자동으로 추가**해요. 자동으로 닫히지 않으며 `건너뛰기`나 `마이페이지에서 자세히 보기`를 눌러야 닫혀요. (마이페이지의 `브리핑 다시 보기`로 다시 열기)
2. **① 마이페이지** — 프로필, 건강 정보, 식단 목표, 오늘의 영양, 음식 사진 기록, 최근 7일
3. **② 냉장고 & 오늘의 식단** — 3D 냉장고·소비기한 알림·층별 위치와 추천 레시피를 한 페이지에.
   재료를 누르면 그 재료로 만들 수 있는 메뉴가 바로 나오고, 오늘·내일까지인 재료를 쓰는 레시피는 주황 테두리와 리본으로 강조돼요.
4. **③ 웨어러블 건강 데이터** — 혈당·혈압(수축기/이완기)·심박수·산소포화도·심전도·체온·활동량 7개 카드
   - 상태: ✅ **안정**(목표 범위 안) / ⚠️ **주의**(범위에 근접하거나 벗어남) / 🚨 **확인 필요**(위험 기준을 크게 벗어남)
   - 카드를 누르면 **최근 12시간 그래프**(시간·값·현재값·기준 범위 표시, 마우스를 올리면 시각별 값)와 **개인 기준 범위 설정**이 열려요.
   - 심전도는 파형과 시연용 기준표(심박·PR·QRS·QTc), 활동량은 개인 목표 대비 달성률로 판정해요.
   - `🎬 상황 시뮬레이션`(식후 혈당 급상승, 혈압 상승, 운동, 저혈당, 미열)으로 상태와 추천이 바뀌는 모습을 보여줄 수 있어요.

**🛒 장바구니** (상단 버튼) — 브리핑이나 레시피 화면의 `장바구니에 담기`로 모인 재료를 네이버쇼핑·쿠팡 낮은가격순 링크로 바로 사고, 산 재료를 체크한 뒤 `냉장고에 넣기`를 누르면 냉장고에 들어가요.

> 데모 데이터를 처음 상태로 돌리려면 마이페이지의 `↺ 데모 초기화`를 두 번 누르세요. 모든 건강 수치는 가상 데이터이며 의학적 진단을 대신하지 않아요.

## 주요 기능

### 3D 냉장고

상단의 **내 냉장고를 한눈에** 탭에서 냉장고를 입체적으로 둘러볼 수 있습니다. 외부 라이브러리나 API 키 없이 CSS 3D로 동작합니다.

- 4개 층에 식재료를 배치하고 좌우 회전, 문 열기·닫기를 할 수 있습니다.
- 재료나 층별 목록을 누르면 위치와 기한을 확인할 수 있습니다.
- 위치를 직접 옮기는 기능 없이, 보관 층·좌우·앞뒤 위치를 확인합니다. 향후 냉장고 카메라가 인식한 재료 위치를 보여주는 방향의 시연 화면입니다.
- D-day는 남은 기한 10일 이내부터 표시하며, 3일 이내 재료와 기한이 지난 재료는 큰 알림으로 강조합니다. 날짜 자체는 재료 상세에서 확인할 수 있습니다.
- 기존 재료는 자동 배치되며 위치는 기존 냉장고 데이터와 함께 브라우저에 저장됩니다.
- 아래의 재료 등록·삭제 및 조리 완료에 따른 재고 변경이 3D 화면에도 반영됩니다.
- 식재료는 이모지 카드로 표현되며 실제 냉장고 내부를 촬영·인식하는 기능은 아닙니다.


### 🎯 여러 목표 함께 고르기

**오늘의 식단 → 나의 식단 목표**에서 목표를 여러 개 함께 고를 수 있어요. (예: `🩸 당뇨 관리 + 🥗 다이어트`)

- 선택한 목표들의 기준을 **모두 합산**해서 점수를 매기므로, 저칼로리이면서 혈당도 완만한 메뉴가 위로 올라와요.
- 칼로리 목표는 다이어트/벌크업이 있으면 그 값을, 없으면 가장 낮은 값을 쓰고, 단백질은 가장 높은 값을 써요.
- 다이어트와 벌크업은 서로 반대라서 함께 고를 수 없고, `⚖️ 균형 식단`을 누르면 나머지가 해제돼요.

### ⌚ 웨어러블 연동 시연 (발표용 시뮬레이션)

스마트워치와 연속혈당측정기(CGM)에서 **혈당·혈압·심박·걸음·수면** 데이터를 받아, 지금 몸 상태에 맞게 추천을 바꾸는 과정을 보여줘요.

- `🔗 기기 연결하기` → 기기 페어링 애니메이션 → 1.2초마다 측정값이 실시간으로 들어오고 그래프가 움직여요.
- `🎬 상황 바꿔보기`: 평소 / 식후 혈당 급상승 / 짠 음식 후 혈압 상승 / 운동 직후 / 저혈당 주의 — 상황에 따라 경고와 **추천 레시피 순위가 바뀌어요.**
  - 혈당 높음 → 저GI·저당 메뉴, 혈압 높음 → 저염 메뉴, 운동 직후 → 고단백 회복식, 저혈당 → 빠른 탄수화물 + 대처 안내
- `▶ 자동 시나리오`: 9초마다 상황이 자동으로 바뀌어 손을 쓰지 않고 발표할 수 있어요.
- AI 상담에서 "지금 내 혈당에 맞는 메뉴"라고 물으면 웨어러블 측정값을 보고 답해요.
- 모든 수치는 시뮬레이션이며 의학적 진단을 대신하지 않아요.

### 💬 AI 식단 상담 (상단 버튼)

화면 오른쪽 위 **💬 AI 식단 상담**을 누르면 대화창이 열립니다. 상담사는 **내 식단 목표·냉장고 재료(유통기한)·오늘 먹은 음식**을 보고 답해요.

- "오늘 뭐 먹지?", "유통기한 임박 재료", "남은 칼로리는?", "두부로 만들 수 있는 요리", "장보기 목록" 등 — 답변 아래 버튼으로 레시피·화면에 바로 이동
- Claude API 키가 있으면 **실제 AI(Claude)** 가 답하고, 없으면 같은 앱 데이터로 답하는 **데모 상담사**가 동작합니다.

### 👤 마이페이지 — 음식 사진으로 식단 자동 기록

- **📸 오늘 먹은 음식 기록**: 사진을 찍거나 올리면 메뉴를 추정하고 칼로리·단백질·탄수화물·지방·나트륨을 분석 → 양(×0.5~×2)과 끼니를 고른 뒤 **등록하면 오늘 목표에 자동 반영**
  - Claude API 키가 있으면 실제 AI가 사진을 분석하고, 없으면 **데모 추정**(사진 색감 + 음식 DB 32종)으로 결과를 보여줍니다. 결과가 틀리면 후보·검색으로 바로 바꿀 수 있어요.
- **📊 오늘의 영양**: 칼로리 링 + 영양소별 목표 대비 막대, 목표(다이어트/당뇨/고혈압 등)에 맞춘 한 줄 코치
- **📅 최근 7일**: 날짜별 칼로리 그래프 (발표용 `지난 6일 기록 채우기` 버튼)
- 프로필(닉네임·아바타), 연속 기록 일수, 목표 달성 일수

### 📹 냉장고 카메라 시연 (발표용 시뮬레이션)

상단의 **📹 냉장고 카메라 시연** 탭은 실제 냉장고 없이 "냉장고 천장 카메라가 재료를 인식해 자동 등록하는" 과정을 보여주는 화면입니다.

- 카메라 화면처럼 보이는 냉장고 내부(4층 + 야채칸)에 지금 냉장고 재료가 **인식 박스·이름·신뢰도**와 함께 표시됩니다.
- 오른쪽 **장바구니**의 재료를 **누르면** 종류에 맞는 칸(유제품 4층, 반찬 3층, 고기·생선 2층, 채소·과일 1층)에, **카메라 화면으로 끌어다 놓으면** 놓은 칸에 들어갑니다.
- 넣는 순간 `문 열림 감지 → AI 인식 중 → ✅ 등록` 애니메이션 후 **실시간으로** 냉장고 목록·3D 냉장고·추천 레시피에 반영되고, 추천 1위가 바뀌면 `NEW`로 알려줍니다.
- 화면 속 재료를 누르고 **✋ 꺼내기**를 누르면 꺼낸 것으로 인식해 목록에서 빠집니다.
- **▶ 자동 시연**: 재료 8개를 차례로 넣어 손을 쓰지 않고 발표할 수 있습니다. **🧹 냉장고 비우기**로 처음부터 다시 시작할 수 있습니다.
- 인식 결과(신뢰도 등)는 시연용으로 만든 값이며, 실제 카메라 영상을 분석하지는 않습니다.

> 발표 팁: 시작 전에 `🧹 냉장고 비우기` → `▶ 자동 시연`을 누르면 빈 냉장고가 채워지면서 추천 레시피가 바뀌는 과정을 보여줄 수 있어요.

| 기능 | 설명 |
|---|---|
| 🎯 식단 목표 | 다이어트 · 벌크업 · 당뇨 관리 · 고혈압 관리 · 균형 식단 중 선택, 하루 칼로리/단백질 목표 설정 |
| 🧊 내 냉장고 | 재료와 유통기한을 등록하면 D-day 순으로 정렬, 임박(D-3 이내)·만료 재료 표시 |

| 📷 사진으로 재료 추가 | **영수증**을 찍으면 산 재료를, **포장 라벨**을 찍으면 재료+소비기한을 자동 인식 → 확인 후 냉장고에 추가 |
| 📊 오늘 식단 기록 | "다 만들었어요"를 누르면 칼로리·단백질 진행률에 반영, 사용한 재료는 냉장고에서 자동 정리 |

데이터(냉장고·기록)는 **각 방문자의 브라우저에 따로 저장**돼요. 링크로 들어온 친구는 자기만의 냉장고를 쓰게 됩니다.

## 🚀 1. 내 PC에서 실행하기

### 준비물
- **Node.js** (LTS 버전, 18 이상) — https://nodejs.org 에서 설치
  - 설치 확인: 명령 프롬프트(cmd)에서 `node -v` 입력 → `v20.x.x` 처럼 나오면 OK
  - Node.js가 없고 Python만 있어도 `start.bat`이 자동으로 Python 서버로 실행해요. (이 경우 최저가 API·AI 인식은 꺼지고 무료 방식으로 동작)

### 실행
**방법 A — 더블클릭 (가장 쉬움)**
1. `jisik` 폴더의 **`start.bat`** 더블클릭
2. 검은 창에 주소가 나오면 브라우저에서 **http://localhost:3000** 접속

**방법 B — 명령어**
```bash
cd jisik
node server.js
# 포트를 바꾸려면 (윈도우 cmd)
set PORT=8080 && node server.js
```

> 처음 실행할 때 **Windows 방화벽** 창이 뜨면 **"개인 네트워크" 허용**을 눌러주세요. (같은 와이파이에서 접속하려면 필요)

서버를 끄려면 검은 창에서 `Ctrl + C` 또는 창을 닫으면 됩니다.

## 🌐 2. 다른 사람이 링크로 들어오게 하기

### ① 같은 와이파이/학교·회사 네트워크에 있는 사람
`start.bat`을 실행하면 이런 줄이 나와요.
```
같은 와이파이/네트워크: http://192.168.0.12:3000
```
이 주소를 공유하면 같은 네트워크의 휴대폰·PC에서 바로 접속할 수 있어요.

### ② 인터넷 어디서나 (추천) — Cloudflare Tunnel, 무료·가입 불필요
1. **`share.bat`** 더블클릭
   - 서버가 꺼져 있으면 자동으로 켜고,
   - `cloudflared`가 없으면 `winget`으로 자동 설치해요. (설치 후 안 되면 창을 닫고 한 번 더 실행)
2. 창에 나오는 **`https://○○○○.trycloudflare.com`** 주소를 복사해서 공유!
   ```
   Your quick Tunnel has been created! Visit it at:
   https://example-words-here.trycloudflare.com
   ```
3. 이 창과 서버 창이 **켜져 있는 동안만** 접속돼요. 닫으면 링크도 사라지고, 다시 실행하면 새 주소가 생겨요.

수동으로 하고 싶다면:
```bash
winget install --id Cloudflare.cloudflared
cloudflared tunnel --url http://localhost:3000
```

> 💡 **대안:** ngrok(`ngrok http 3000`, 가입 필요)도 같은 방식으로 쓸 수 있어요.

### ⚠️ 공유할 때 주의
- 내 PC가 **켜져 있고 절전 모드가 아니어야** 해요.
- `public` 폴더 안의 파일만 공개되고, PC의 다른 파일은 보이지 않아요.
- 임시 링크(trycloudflare)는 테스트·발표용이에요. 상시 운영은 GitHub Pages·Netlify 같은 무료 호스팅에 `public` 폴더를 올리는 걸 추천해요.

## 🔑 3. 선택 기능 켜기 (최저가 · AI 사진 인식)

키를 넣지 않아도 모든 기능이 **무료 방식으로 동작**해요. 키를 넣으면 더 좋아집니다.

| 기능 | 키 없을 때 (기본) | 키 넣으면 |
|---|---|---|
| 💸 최저가 | 쇼핑몰을 '낮은 가격순'으로 연 검색 링크 | 앱 안에서 실시간 최저가 순위 8개 + 합계 (네이버 쇼핑 API, **무료**·하루 25,000회) |
| 📷 사진 인식 | 브라우저 무료 OCR (Tesseract.js) — 깔끔한 영수증·라벨은 잘 읽음 | Claude AI 이미지 인식 — 구겨진 영수증, 줄임말 상품명도 잘 읽음 (**유료**, 사진 1장당 몇 원 수준) |
| 💬 AI 상담 | 앱 데이터 기반 데모 상담사 (정해진 질문 유형에 답함) | Claude가 자유로운 질문에 내 냉장고·식단을 보고 답함 (**유료**, 대화 1번에 몇 원 수준) |
| 🍽️ 음식 사진 분석 | 데모 추정 (사진 색감 + 음식 DB) | Claude가 메뉴·양·영양성분 추정 (**유료**) |

### ① 네이버 쇼핑 API 키 발급 (무료)
1. https://developers.naver.com 접속 → 로그인 → **Application → 애플리케이션 등록**
2. 사용 API: **검색** 선택, 환경: **WEB 설정** → URL에 `http://localhost:3000` 입력 → 등록
3. 발급된 **Client ID / Client Secret** 복사

### ② (선택) Claude API 키 발급
1. https://console.anthropic.com 접속 → **API Keys → Create Key** (결제 수단 등록 필요)

### ③ config.json 만들기
`config.example.json`을 복사해서 이름을 **`config.json`** 으로 바꾸고 키를 넣어주세요. 안 쓰는 키는 `""`로 두면 돼요.
```json
{
  "naverClientId": "abcdEFGH1234",
  "naverClientSecret": "XyZ123abc",
  "anthropicApiKey": "sk-ant-...",
  "anthropicModel": "claude-haiku-4-5"
}
```
서버(start.bat)를 **껐다 다시 켜면** 검은 창에 `최저가 검색 … 켜짐 ✅` 처럼 표시돼요.

> 🔒 키는 서버(내 PC)에만 있고 방문자 브라우저로는 전송되지 않아요. `config.json`은 다른 사람에게 공유하거나 GitHub에 올리지 마세요. (`.gitignore`에 포함됨)

### 📷 사진 인식 사용 팁
- 휴대폰으로 공유 링크(https)에 접속 → `📷 사진으로 추가` → **카메라로 찍기**
- 영수증: 밝은 곳에서 평평하게, 글자가 화면을 가득 채우게. 구매일은 유통기한으로 쓰지 않고 **재료별 기본 보관 기간**이 자동으로 들어가요.
- 라벨: 제품명과 **소비기한(유통기한)** 이 함께 보이게 찍으면 날짜까지 자동 입력
- 인식 결과는 바로 넣지 않고 **확인 화면**에서 이름·날짜를 고치거나 빼고 추가할 수 있어요.
- 무료 OCR은 처음 한 번 한글 인식 데이터(약 2MB)를 내려받아요. 인터넷이 연결돼 있어야 해요.
- 온라인 장보기 주문 내역은 사진 대신 **글자로 붙여넣기**를 쓰면 가장 정확해요.

## 🧑‍🍳 사용 방법
1. **목표 선택** — 왼쪽 위에서 다이어트/벌크업/당뇨/고혈압/균형 중 선택 (칼로리·단백질 목표는 직접 수정 가능)
2. **냉장고 채우기** — `📷 사진으로 추가`로 영수증·라벨을 찍거나, 재료 이름을 입력하면 유통기한 기본값이 자동으로 들어가요. (처음 방문 시 예시 재료가 채워져 있어요)
3. **추천 확인** — 오른쪽 카드에서 `⏰ 임박`, `✓ 목표 적합`, `🛒 부족 재료`를 한눈에 확인
4. **레시피 열기** — `▶ 자동 재생`으로 전체 과정을 훑어보고, 요리할 땐 `◀ ▶`(키보드 방향키도 가능)와 `⏱ 타이머` 사용
5. **다 만들었어요!** — 오늘 섭취량에 기록되고 사용한 재료는 냉장고에서 빠져요

```js
{

  ingredients: [{ n: "두부", a: "1모" }, { n: "버섯", a: "한 줌", opt: true }],
  steps: [
    { act: "cut", items: ["두부"], text: "두부를 썰어요.", sec: 60 }
    // act: cut, mix, stir, fry, boil, steam, bake, microwave, plate, wash, soak, season
  ]
}
```
