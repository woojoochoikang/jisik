# Photographic food assets

Generated with the built-in image_gen tool for Jisik. These are photorealistic AI-generated examples, not photographs of actual prepared meals or of a user's refrigerator.

- 24 finished-dish photographs match the recipe names and ingredient lists.
- 54 grocery thumbnails cover vegetables, fruit, meat, dairy, grains and shared seasoning categories.
- The exact prompts are recorded in `prompts.json`.
- Runtime files are optimized JPEGs: 960px maximum edge for dishes, 256px for ingredients.
- Original generated PNGs remain in the user's Codex generated_images directory. Runtime assets are stored locally; no third-party image requests are needed.
- Recipe images carry the label `AI 생성 · 조리 예시` in the UI.
